# Stay Standing

A small co-op bullet-hell experiment for the browser. You can't attack. You can only dodge.
If anyone on the team is still standing when a floor's timer runs out, everyone moves on.

**Play:** https://maikonfarias.github.io/stay-standing/

## Features

- 1–4 players: local keyboard, gamepads, and bots fill the empty slots
- A dash with brief invincibility, and you revive fallen teammates by standing next to them
- 3 zones × 4 floors, each zone ending with a boss you can only outlast
- A team bonus after every floor, 7 heroes with passives, and 3 difficulties

## Controls

| | Move | Dash |
|---|---|---|
| P1 | WASD (arrows too when solo) | Space |
| P2 | Arrow keys | Enter |
| Gamepad | Stick / d-pad | A |

In the lobby: A/D picks your hero, B sets the number of bots, T sets difficulty, and Space starts.
P pauses and M mutes.

It's a single `index.html` with no build step and no dependencies.
